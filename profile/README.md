# ACSquaredS

Open-source projects dedicated to applied mathematics, scientific computing and complex algebra.

## MathCraft

**MathCraft** is an open-source, numerical computing environment inspired by MathLab. It is split into modules, each with its own repository:

| Repository | Purpose |
|---|---|
| [MathCraft](https://github.com/ACSquaredS/MathCraft) | Entry point, module map and roadmap |
| [MathCore](https://github.com/ACSquaredS/MathCore) | Shared types, arrays and matrices |
| [MathNumerical](https://github.com/ACSquaredS/MathNumerical) | Linear algebra, solvers and ODE integrators |
| [MathSymbolic](https://github.com/ACSquaredS/MathSymbolic) | Symbolic expressions and calculus |
| [MathStatistics](https://github.com/ACSquaredS/MathStatistics) | Descriptive statistics, distributions and tests |
| [MathVisualization](https://github.com/ACSquaredS/MathVisualization) | 2D and 3D plots |
| [MathSimulation](https://github.com/ACSquaredS/MathSimulation) | Dynamic system simulation |

Every module is in early stage. Start with [MathCraft](https://github.com/ACSquaredS/MathCraft).
